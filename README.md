# RupeeWise — Currency Converter & Trip Budget Planner

Convert between 10 currencies (INR, USD, EUR, GBP, AED, SGD, JPY, AUD, CAD, CHF) with editable indicative rates, and plan trip expenses with auto-conversion to INR, per-day averages, and budget tracking.

- No signup, no backend — all data stays in your browser (localStorage)
- Live: https://abhiramunni.github.io/rupeewise/
